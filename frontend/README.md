# Inventory Management System

This is an inventory management system built with React for the frontend and Node.js for the backend. The application provides features for managing inventory, user roles, purchases, sales, and reporting.

## Features

- **Role-Based Access**: Different user roles with specific permissions.
- **User Management**: Create, update, and delete users.
- **Item Management**: Add, edit, and delete inventory items.
- **Category Management**: Organize items into categories.
- **Purchase Management**: Manage purchase orders and track inventory.
- **Sales/Project Issue Management**: Handle sales and project-related issues.
- **Inventory and Stock Control**: Monitor stock levels and inventory status.
- **Dashboard and Analytics**: Visualize key metrics and analytics.
- **Reporting Module**: Generate various reports based on inventory and sales data.

## Getting Started

### Prerequisites

- Node.js
- npm or yarn
- MongoDB (or your preferred database)

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the frontend directory:
   ```
   cd inventory-management-system/frontend
   ```

3. Install frontend dependencies:
   ```
   npm install
   ```

4. Navigate to the backend directory:
   ```
   cd ../backend
   ```

5. Install backend dependencies:
   ```
   npm install
   ```

6. Set up environment variables in the `.env` files for both frontend and backend.

### Running the Application

1. Start the backend server:
   ```
   cd backend
   npm start
   ```

2. Start the frontend application:
   ```
   cd frontend
   npm start
   ```

The application should now be running on `http://localhost:3000` for the frontend and `http://localhost:5000` for the backend (or your specified port).
